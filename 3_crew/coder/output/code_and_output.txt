The Python code to calculate the series is as follows:

```python
def calculate_series(terms):
    total = 0.0
    for i in range(terms):
        term = 1 / (2 * i + 1)
        if i % 2 == 0:
            total += term
        else:
            total -= term
    return total * 4

result = calculate_series(10000)
print(result)
```
